# Модели Argos

Файлы `translate-en_ru-1_9.argosmodel` и `translate-ru_en-1_9.argosmodel` не включены в репозиторий: каждый больше 100 МБ, а GitHub не принимает такие файлы в обычный git.

Они уже находятся внутри установщика. После установки модели лежат в `resources\argos`.  
Для запуска из исходников скопируйте оба файла в эту папку из установленной программы.
