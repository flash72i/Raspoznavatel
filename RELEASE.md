# Публикация на GitHub

## 1. Репозиторий

Загрузите содержимое этой папки в репозиторий GitHub. Для больших файлов используйте GitHub Desktop или git: веб-загрузка ограничена 25 МБ.

## 2. Релиз

Установщик **не коммитится** в git: его размер 471 782 370 Б, а лимит GitHub — 100 МБ на файл.

Создайте **Release** с тегом `v2.7.0-beta`, отметьте его как pre-release и прикрепите файл:

`Raspoznavatel-2.7.0-Setup.exe`

SHA256:

`21B9AE7DF9C75092E404F3E40AA4C278E242F8DE68AF06B9D37D2B8F9EEE7155`

## 3. Проверка

- В репозитории не должно быть `Raspoznavatel_data`, `Screenshots`, `.venv`, `dist`, `build`, `installer_custom/archive`.
- В релизе должен быть ровно один установщик.
- Приложение должно запускаться без заставки.
